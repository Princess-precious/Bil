BIL

BIL is a modern article and editorial website built with React and TypeScript.

The website presents articles and visual content across different creative
topics, including Architecture & Design.

Technologies

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Swiper

Features

- Responsive navigation
- Search interface
- Category navigation
- Article sections
- Image carousel
- Responsive design

## Project Status

🚧 This project is currently in development.
